# Security Policy

## Supported versions

This is a study project, so only the latest code on the `main` branch receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately through GitHub's [private vulnerability reporting](https://github.com/gabrantoniette/students-categorization/security/advisories/new) instead, including:

- a description of the problem and its impact;
- steps to reproduce it, or a proof of concept;
- the affected files or dependency versions, if you know them.

The project is maintained in spare time, so a reply may take a few days. Once the problem is confirmed, a fix will be prepared and the advisory will be published after the fix is released.
